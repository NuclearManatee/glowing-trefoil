# Install

One path per harness. Every command runs the same CLI through
`npx -y glowing-trefoil <command>`, so nothing needs a global binary, a
`bun link`, or a plugin-local `node_modules`.

Prerequisite for every harness: **Node 22+** at command time.

## Claude Code

Requires Claude Code `2.1.292` or later.

```sh
claude plugin install script-forge --marketplace NuclearManatee/glowing-trefoil
```

- Installs at user scope by default: available in every project.
- The shell install does not prompt for `userConfig`; the manifest defaults
  apply. To change values later: `/plugin configure script-forge@glowing-trefoil`.
- Verify: `/script-forge:scaffold` appears.

Update:

```sh
claude plugin update script-forge@glowing-trefoil
```

Uninstall:

```sh
claude plugin uninstall script-forge@glowing-trefoil
```

## Cowork

1. Open **Customize → Plugins**.
2. Choose **Add → Add marketplace**.
3. Enter `NuclearManatee/glowing-trefoil`.
4. Install `script-forge`.

Cowork loads the same `.claude-plugin` artifact as Claude Code. The plugin has
no top-level `bin/`, no `package.json`, and no `node_modules`.

- `userConfig` is not prompted; defaults apply.
- Project overrides go in `.script-forge.json` in the connected folder.
- The sandbox has Node/npm and an allowlisted npm registry, so
  `npx -y glowing-trefoil ...` works.
- Bun is not guaranteed. `scaffold` creates the workspace and skips
  `bun install`, printing the command to run once Bun is available. `doctor`
  reports the missing Bun as a failure.

Verify: `/script-forge:scaffold` appears and a scaffold task runs.

## Cursor

```sh
npx -y glowing-trefoil install cursor
```

Then **Command Palette → Developer: Reload Window**.

What it does:

- copies `plugins/script-forge/` to `~/.cursor/plugins/local/script-forge/`;
- writes `.glowing-trefoil.json` inside that folder;
- replaces only that folder; other local plugins are untouched;
- refuses to overwrite a folder without the marker unless `--force` is passed.

Verify: `/script-forge-scaffold` appears and the `anvil` skill is listed.

Update: re-run the install command. Uninstall:

```sh
npx -y glowing-trefoil uninstall cursor
```

Alternative for sharing, through Cursor's marketplace surface:

```sh
cursor-agent plugin marketplace add https://github.com/NuclearManatee/glowing-trefoil
```

Then install `script-forge` from Customize or `/plugin`. Cursor has no
non-interactive plugin install command, so this path is UI-driven.

Enterprise admins can disable local plugin imports; the marketplace path is the
fallback.

## OpenCode

```sh
npx -y glowing-trefoil install opencode
```

Then restart OpenCode.

What it does:

- copies `commands-opencode/script-forge-*.md` to
  `~/.config/opencode/commands/`;
- copies `skills/anvil/` to `~/.agents/skills/anvil/`;
- never edits `opencode.json(c)`;
- replaces only files it owns. Each generated command carries a
  `<!-- generated by glowing-trefoil -->` marker; the skill folder carries
  `.glowing-trefoil.json`.

Verify: `/script-forge-scaffold` is registered and `@anvil` is discoverable.

Update: re-run the install command. Uninstall:

```sh
npx -y glowing-trefoil uninstall opencode
```

## Config on every harness

The plugin works with defaults. Portable layers, highest to lowest:

1. CLI flags.
2. Project `.script-forge.json`.
3. Claude Code `userConfig`.
4. Global `~/.config/script-forge/config.json`.
5. Defaults.

Claude Code and Cowork pass `userConfig` as `--claude-config-json`. Cursor and
OpenCode use the portable layers only.

```json
{
  "defaultNamespace": "tools",
  "scriptsDirectory": "scripts",
  "localDirectory": "local"
}
```

Inspect the resolved values and their sources:

```sh
npx -y glowing-trefoil config
npx -y glowing-trefoil config --json
```

## Requirements and limits

- **Node 22+** is required for the CLI on every harness.
- **Bun 1.3.14** is required to install and run a generated workspace.
- `npx` needs network access on first run; later runs use the npm cache.
- Claude `userConfig` values are interpolated into a shell command as JSON in
  single quotes. Values containing single quotes are unsupported.
- Marketplace installs (Claude Code, Cowork, Cursor marketplace) are copies.
  An npm publish does not update them; use the update command above.
